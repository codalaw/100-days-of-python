# Day 3 - Conditional Statements & Logic

## 100 Days of Python Challenge

### Overview
On Day 3, I learned how to make decisions in Python using conditional statements and logical operators.

Instead of building one large project, I completed three smaller exercises to practice these concepts.

## What I Learned
- Using `if`, `elif`, and `else` statements
- Comparison operators (`>`, `<`, `>=`, `<=`, `==`)
- Logical operators such as `and`
- Checking multiple conditions
- Using `range()` to check whether a number falls within a range
- Basic input validation
- Working with Boolean values

## Projects

### 1. Age Checker (`age_checker.py`)
A simple program that asks for the user's age and determines whether they are old enough to drive.

### 2. Grade Checker (`grade_checker.py`)
A program that accepts a numerical test score and determines the corresponding letter grade.

Features include:
- Letter grades A through F
- Invalid score detection
- Special message for a perfect score

### 3. Movie Theater Checker (`movie_checker.py`)
A program that determines whether someone can enter a movie theater based on their age and whether a parent is present.

## Reflection
Today I practiced writing programs that respond differently depending on user input.

I also learned the importance of testing boundary values and checking for invalid inputs.

One interesting discovery was using `range()` inside an `elif` statement.

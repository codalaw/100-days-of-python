# Day 001 - Personal Introduction Generator

Part of my **100 Days of Python** challenge.

## About

For my first project, I created a simple Python program that asks the user a few questions about themselves and generates a personalized introduction using their answers.

I also added a small loading animation using the `time` module to make it a little more interesting.

## What I Used

- Python 3
- Variables and user input
- F-strings
- For loops
- The `time` module

## What I Learned

This was a good refresher on some of the basics of Python, particularly working with variables, user input, and strings.

I originally had the loading animation written out with multiple `time.sleep()` and `print()` statements. After looking into loops, I was able to clean that up using a `for` loop.

I also learned that I didn't need to convert the user's age into an integer since I wasn't doing any calculations with it.

## Running the Program

Make sure Python 3 is installed, then run:

`python main.py`

Answer the questions and the program will generate your introduction.

## Things I Could Improve

- Add input validation.
- Allow the user to restart without closing the program.
- Save the generated introduction to a file.

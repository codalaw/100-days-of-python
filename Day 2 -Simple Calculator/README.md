# 🐍 Day 2 — Tip Calculator

## 📖 About the Project

This is Day 2 of my **100 Days of Python Challenge**!

For this project, I built a simple tip calculator using Python. The program asks the user for their restaurant bill, their desired tip percentage, and how many people are splitting the bill.

It then calculates the total cost, including the tip, and determines how much each person needs to pay.

## 🚀 Features

- Accepts a restaurant bill amount from the user.
- Allows the user to choose a tip percentage.
- Calculates the total bill including the tip.
- Splits the bill evenly between multiple people.
- Displays each person's share formatted to two decimal places.

## 🧠 What I Learned

During this project, I practiced:

- **Variables:** Storing user inputs and calculated values.
- **`input()`:** Collecting information from the user.
- **`int()` and `float()`:** Converting user input into numbers.
- **Mathematical operators:** Using multiplication, division, and addition.
- **F-strings:** Displaying variables inside text.
- **Decimal formatting:** Using `:.2f` to display monetary values.

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Download or clone this repository.
3. Open the project folder in your terminal.
4. Run the following command:

```bash
python tip_calculator.py
```

5. Follow the prompts to calculate your bill.
